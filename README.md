# 2025-1 WebProject

## Travel Planner
AI 여행 플래너는 사용자가 국내 축제를 발견하고 AI 기반 플래너의 도움을 받아 여행을 계획할 수 있도록 설계된 웹 애플리케이션입니다. 사용자는 축제 목록을 탐색하고, 각 축제에 대한 상세 정보를 확인한 후, AI가 추천해주는 맞춤형 여행 일정을 만들 수 있습니다.

## 주요 기능
AI 기반 여행 계획:
개인 맞춤형 여행 추천 및 계획을 위한 대화형 채팅 인터페이스 제공.<br>
축제 정보 검색:
"국내 축제 목록"을 통해 다양한 국내 축제 정보를 탐색.<br>
각 축제에 대한 상세 정보 보기:
축제명 및 설명.
행사 기간.
위치 (통합 지도 보기 포함, 예: 카카오맵).<br>
통합 여행 계획:
축제 상세 정보 페이지에서 "이 축제로 여행 계획 세우기" 버튼을 통해 바로 여행 계획 시작 가능.
