# 2025-1 WebProject

## Travel Planner
전국의 다양한 축제 정보를 한눈에 모아보고, AI를 통해 손쉽게 여행 일정을 짤 수 있는 웹 서비스입니다.
공공데이터 API로 지역 축제 정보를 제공하며, Gemini AI가 조건에 맞는 최적의 여행 경로를 추천해 사용자들의 간편한 여행 계획과 지역 경제 활성화를 목표로 하고자 합니다.

## 주요 기능
### AI 여행 계획
개인 맞춤형 여행 추천 및 계획을 위한 대화형 채팅 인터페이스 제공.<br>
### 축제 정보 검색
국내에서 진행되는 다양한 축제 정보를 한눈에 확인할 수 있습니다.

- **축제 목록**
  - 국내 다양한 축제 정보 조회
  - 축제명 및 행사 기간 확인

- **축제 상세 정보**
  - 축제 설명 및 행사 기간 확인
  - 카카오맵을 통한 축제 위치 지도 보기

- **통합 여행 계획**
  - 축제 상세 페이지에서 **「이 축제로 여행 계획 세우기」** 버튼을 통해
    해당 축제를 포함한 여행 계획을 바로 시작할 수 있습니다.
